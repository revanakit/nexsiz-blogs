Build & Installation

Requirements

  • Rust toolchain (1.87+ recommended, or stable)
  • Linux (primary target; SHM & Frida support)
  • Optional: Frida tools for grey-box coverage

Default build (minimal dependencies)

shell
cargo build --release
# Binary: ./target/release/nexsiz

With LibAFL support

shell
cargo build --release --features libafl

Build official NXS binaries

shell
cd nxs && ./build.sh
# Produces nxs/bin/nxs-*

Quick Start

1. Prepare a seed corpus

shell
mkdir -p seeds/ftp
echo -e "USER anonymous\r\nPASS guest\r\nPWD\r\nQUIT\r\n" > seeds/ftp/login.txt

2. Basic campaign

shell
./target/release/nexsiz \
  -h 127.0.0.1 -p 21 -m ftp \
  -s seeds/ftp -o output/ftp -v -x 50000

3. Campaign with NXS deepening

shell
cd nxs && ./build.sh && cd ..
./target/release/nexsiz -h 127.0.0.1 -p 21 -m ftp --nxs default -v

Campaign Examples

Basic FTP campaign

shell
nexsiz -h 127.0.0.1 -p 21 -m ftp -s seeds/ftp -o out/ftp -v

With default NXS set

shell
nexsiz -h 127.0.0.1 -p 21 -m ftp --nxs default -v

List resolved NXS paths

shell
nexsiz --nxs default --nxs-list

Intrusive NXS with tighter rate limits

shell
nexsiz -h 10.0.0.5 -p 21 -m ftp --nxs intrusive --nxs-cooldown 60 -v

Grey-box with Frida SHM coverage + RPC

shell
nexsiz -h 127.0.0.1 -p 21 -m ftp -C map --shm demo -Y /tmp/nexsiz.sock -v

Deep oracle (diffsan)

shell
nexsiz -h 127.0.0.1 -p 21 -m ftp -O diffsan -s seeds/ftp -o out/deep -v

Output Layout

directory tree
output/
├── crashes/          # Crashing inputs (and .min when minimisation succeeds)
├── hangs/
├── nxs-meta/         # Metadata JSON written prior to each NXS spawn
├── nxs-out/          # Per-event NXS artefact trees (report.json, …)
├── nxs-findings/     # Secondary findings (exit code 2) in JSONL form
└── queue/

Frida Coverage Agent

External grey-box instrumentation that injects an AFL-style 64 KiB edge map into POSIX shared memory.

Terminal A – instrument the target

shell
export NEXSIZ_SHM_ID=demo
# Optional: constrain Stalker to a single module
export NEXSIZ_COV_MODULE=mydaemon
frida -l agents/frida/nexsiz_cov.js -f ./mydaemon --no-pause

Terminal B – fuzz with live SHM coverage

shell
export NEXSIZ_SHM_ID=demo
./target/release/nexsiz -h 127.0.0.1 -p 21 -m ftp -C map --shm demo -v

Modes: NEXSIZ_COV_MODE=stalker (default, higher fidelity) or exports (lighter, lower noise). Clean residual maps with rm /dev/shm/nexsiz-cov* when finished.

NXS Quick Reference

For the full NXS contract, search path, exit codes, and custom script authoring, see the dedicated NXS page.

shell
# Enable default (safe) set
nexsiz ... --nxs default -v

# Resolve paths without running a campaign
nexsiz --nxs default --nxs-list

# Rate-limited intrusive set
nexsiz ... --nxs intrusive --nxs-cooldown 60 --nxs-max-per-event 20 -v

# External webhook notification
export NXS_WEBHOOK_URL=http://127.0.0.1:9000/hook
nexsiz ... --nxs external -v
